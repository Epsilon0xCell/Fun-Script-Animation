Fun-Script-Animation

I wrote one bash script, animation.sh, 124 lines, that puts a rocket on a sine wave across a field of 50 stars in a terminal and leaves it there until I press Ctrl+C. This page is the room it waits in: the stage is up top, the playbill sits beside it, and the script itself is printed below like the text of the play.

Frame 31 of 31

The stage replay: 31 frames I captured on 2026-10-31 by running animation.sh in a pty set to 80 columns by 24 rows, then reading the position escapes back into a grid. The rocket enters at row 12, column 1, sinks to row 17 at the bottom of the wave, and is back at row 13 by frame 31. One honest note on how I got them: this machine has no bc, and the script needs bc for its sine math, so for the capture run only I put a small stand-in bc on the path that answers the two sums the script asks for. The drawing, the star placement, the pacing of positions, and every escape printed are the script's own. The player starts paused on the last frame. Press Play and it runs from frame 1 to frame 31 once, then stops. It does not loop.

The playbill

What happens, in order

  1. Before the curtain I check for bc first. The sine math calls bc twice per frame, so a missing bc gets one clear refusal and exit code 1, not errors on every frame.
  2. The set is placed 50 stars go down once, each at 1 + RANDOM % width by 1 + RANDOM % height, each given one character out of . * and + that it keeps for the whole run.
  3. The curtain instruction I register the cursor restore, trap "tput cnorm" EXIT, before anything hides the cursor. Ctrl+C later gives the cursor back.
  4. The crossing The rocket starts at column 1 on the middle row and moves 2 columns per frame at about 20 frames per second, one printed buffer per frame so the terminal never repaints half a picture.
  5. The wave The row is worked out fresh each frame: middle row plus 5 * s(angle) through bc, the angle growing by 0.1 per frame. On my captured run that took the rocket from row 12 down to row 17 and back up.
  6. The turn At column width - 2 on the right and column 1 on the left the speed flips sign. The test is >= and <= because a 2 column step can jump past the exact edge.
  7. No final act There is no ending in the script. The loop runs until Ctrl+C, and the EXIT trap restores the cursor on the way out.

Two limits I left in and will say out loud: the terminal size is read once at the start, so resizing the window mid-run keeps the old size until a restart, and in a terminal shorter than about 11 rows the fixed 5 row wave does not fit, so I clamp the row to the screen instead of printing an invalid row 0.

When bc is not in the room

This capture needs no stand-in and no pty. On 2026-10-31 I ran the script on this machine, which has tput but no bc, and this is the whole of what it printed. I count this as the script behaving well: it names the missing tool and the reason, exits with code 1, and draws nothing.

The script of the play

These are lines from animation.sh at the head I built this page from, with their real line numbers. I picked the six places where the script can go wrong in a way a viewer would notice: the missing tool, the missing size, the hidden cursor, the half-painted frame, the missed edge, and the row that leaves the screen.

The refusal, lines 12 to 15

Checked before anything is drawn. Without bc the two sine calls per frame fail every frame and the rocket never moves, so the script says so once and stops.

12if ! command -v bc >/dev/null 2>&1; then
13    echo "animation.sh needs bc for the sine-wave motion, and bc was not found in PATH." >&2
14    exit 1
15fi

The size, lines 22 to 25

If tput cannot report a size, the fallback is 80 by 24, and a zero is replaced the same way, so no division later ever sees a zero height.

22width=$(tput cols 2>/dev/null || echo 80)
23height=$(tput lines 2>/dev/null || echo 24)
24[ "$width" -gt 0 ] 2>/dev/null || width=80
25[ "$height" -gt 0 ] 2>/dev/null || height=24

The restore, line 33

One line, registered before the loop and before the cursor is hidden. An earlier version of this script had the trap after the infinite loop, where it could never run, and Ctrl+C left the cursor hidden.

33trap "tput cnorm" EXIT

One frame, one write, lines 87 to 93

All 50 stars and the rocket go into one buffer, printed with a single echo -ne. Separate writes would let the terminal repaint between stars and rocket, which reads as flicker.

87    for ((i=0; i<num_stars; i++)); do
88        buffer+=$(printf "\033[%s;%sH%s%s%s" "${stars_y[$i]}" "${stars_x[$i]}" "$C_STARS" "${stars_char[$i]}" "$C_RESET")
89    done
90
91    buffer+=$(printf "\033[%s;%sH%s🚀%s" "$y" "$x" "$C_ROCKET" "$C_RESET")
92
93    echo -ne "$buffer"

The turn, lines 99 to 102

The rocket moves 2 columns per frame, so it can step past the exact edge column. The bounce test uses >= and <= for that reason.

99    x=$((x + x_speed))
100    if [ $x -ge $((width - 2)) ] || [ $x -le 1 ]; then
101        x_speed=$((x_speed * -1))
102    fi

The wave and the clamp, lines 109 to 118

The row is derived fresh from the middle each frame, so rounding cannot drift it over a long run. The clamp at the end is the fix for short terminals: the wave is 5 rows each way, and a row of 0 or a row past the bottom is an invalid position escape, so the row is held inside the screen.

109    angle=$(echo "$angle + $y_step" | bc -l)
110    y_offset=$(echo "$y_amp * s($angle)" | bc -l)
111    y=$(( height / 2 + $(printf "%.0f" "$y_offset") ))
112    # My amplitude is fixed at 5 rows, so on a terminal shorter than
113    # about 11 rows the wave would push the rocket to row 0 or past
114    # the last row, and the position escape for those rows is invalid.
115    # I clamp to the screen instead of trusting the terminal to be
116    # tall enough for the wave I chose.
117    [ "$y" -lt 1 ] && y=1
118    [ "$y" -gt "$height" ] && y=$height

Run it yourself

$ bash animation.sh

Stop it with Ctrl+C. The script restores the cursor on exit. It needs a terminal, tput, and bc.

Bash bc, two calls per frame tput cols, lines, civis, cnorm 50 stars, placed once sleep 0.05, about 20 frames per second
